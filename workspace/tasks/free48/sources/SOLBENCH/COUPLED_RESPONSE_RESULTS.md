## Exact sparse structural defect

`δ = D*(f_active − F_bulk_context_of_active)`.

Each bulk context subtracts its total signed impulses divided by the number of unretained nodes in that context. This is an exact conservative projection: signed sum zero, mean absolute defect≤2Σ|δ|/N. At512/radius4 there are two interface support sites and eight uniform context coefficients. Scope includes fixed periodic material contexts and retained changed edges/chord endpoints. Arbitrary within-context material/history changes require refinement; the number of necessary contexts can approach N. This is a load-bearing scaling restriction, not concealed in the benchmark.
