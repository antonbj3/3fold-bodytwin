# Frozen criterion — CLOUD-W6-STRENGTH-ID

Split by speed before all fitting: 60 deg/s training, 90 deg/s held-out. Analyze extension and flexion separately. Use raw times/angles/torques, with any sign convention declared before comparing outcomes. The baseline is a per-direction, angle-only interpolated 60 deg/s torque curve with one global 60-to-90 scale selected from training only; since 90 labels are unavailable at fitting, use scale=1 unless a public prior independent of the subject is sourced. Score held-out matched-angle RMSE in Nm on all valid 90 deg/s samples or predeclared 10-degree bins. PASS only if a proposed identifiable individual model reduces held-out RMSE by >=10% for both directions and the sensitivity matrix for all claimed individual parameters has no structural null direction after declared measurements. Also report 60-only fit, uncertainty across strokes, and exact parameter gauges. If held-out overlap or required independent measurement is missing, label that part UNKNOWN. Do not change this gate after seeing 90 deg/s results.
