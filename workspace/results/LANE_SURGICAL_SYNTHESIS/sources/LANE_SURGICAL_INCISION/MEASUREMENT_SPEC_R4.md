# Final measurement specification: scalpel, work port and injury zone

PENDING_INDEPENDENT_REVIEW. This is a proposed acquisition, not executed experiments, achieved precision, a clinical protocol or verified power. Consumer: LANE_SURGICAL_RESPONSE. Targets: BT-CTX-SURG-INCISION, GRAPH_INVERSE/MULTIPHYSICS.

Desired capability → cutting force, new gap and injury zone for a new tool from the same tissue history.
Conflicting requirements → work and actual new fracture surface must be measured simultaneously, while deformation, friction and pre-cleavage work must be identified independently.
Obstacle → a diameter/gauge series changes bevel and contact simultaneously; peakforce and post-extraction crack length are not a joint work port.
Changed operation → synchronous two-component force, 3D crack front and matched first-pass/repeat/precut-work, with explicit drift control and uncertainty ledger.

1. Tissue and lineage. Start with unfixed porcine full-thickness skin and separate anatomically documented layers; never transfer full-thickness skin toughness to a layer without measurement. Register animal, body site, age, thickness, temperature, hydration, freezing history, fiber orientation and biaxial prestretch. Six independent animals are a pilot default, not a power calculation. Randomize adjacent samples, preserving that they are not the same sample. Hold out one animal and one actual radius entirely from material/contact fitting.
2. Tools. Measure local edge radius along the entire active edge before and after every incision with calibrated profilometry/microscopy; store the curvature field and uncertainty. Proposed manufacturing targets 1/5/20/50µm are only planning values; actual radius governs the analysis. Hold wedge/bevel angle fixed in the first radius series, then a separate angle intervention. Register surface finish, coating, previous use and tissue residue. Shaft diameter/2 must not be set as edge radius. Measure contact imprint and opening before blade arrival for possible coupling to BINDINGS.
3. Synchronous work measurement. Calibrate Ft and Fn with cross-coupling and offset; register x(t),z(t), speed, advance and prestretch load on the same clock. Run, for example, 1 and20mm/s and several penetration depths, but preregister every held-out case. Integrate Wext=∫Ft dx+∫Fn dz, with the entire first passage and ramp-up saved. Sampling frequency and anti-aliasing are chosen according to measured instrument bandwidth so that the work's discretization error fits within the budget; 10Hz peak-only data are insufficient. Fn has zero direct effect at dz=0; Fn/d is never measured cutting toughness.
4. Crack area. Follow the actual advancing front with 3D imaging/DIC and subsequent section imaging. Freeze the reference: one geometric crack-plane area ΔA, not two free surfaces. Report delamination, crushing, perforation, fracture orientation and any difference between loaded area and unloaded trace separately. A delaminated microsurface must not be counted both in a macrocohesive work curve and in an added microsum. Residual traces and needle-hole diameter are not automatic area observations.
5. Separate deformation and contact. Measure recoverable ΔΨ through documented unloading/reloading and included prestretch energy; use the layer operator from R2 only if its membrane/slip assumptions are empirically accepted. Measure Dcontact with precut/repeat through an actually comparable path, contact area, speed and prestretch. Second and third passages quantify conditioning/drift; if spreading/friction work changes between passages, the difference must not be entirely attributed to Γ. Preserve that difference as a nuisance port and run both equality closure and measured drift control.
6. Γ and micromechanics. Effective Γ_cut=(Wext−ΔΨ−Dcontact)/ΔA. Chemical Γ0 additionally requires independent B_before: Γ0=Γ_cut−B_before. BINDINGS full-terminal traction/opening-work, newly formed interfacearea and fiber fracture/pullout must come from matched lineage. A partial hysteresis loop or a radius near zero does not identify B_before. Γ_pierce and Γ_cut remain different assay ports until the same skin, crack kinematics and process mechanisms are measured. Measure needle insertion's first/same-hole/3rd passage with the same work port as the scalpel.
7. Injury zone to RESPONSE. Define width as distance normal to the measured fracture front, per side, layer and time. Report mechanical strain zone, irreversible matrix injury, membrane permeability/cell viability and perfusion loss separately. Perform spatial viability/membrane assay immediately and at, for example,24h, plus vessel imaging with caliber, density and before/after flow. A mechanical strain threshold must first be compared with this independent observation; it is not a necrosis measure. No needle-trace width is passed as an avascular edge to RESPONSE. Wound gap and bleeding flow are measured separately, with suture/boundary conditions documented.

## Frozen prospective error budget

Exact bounded ratio-error bound, when Ahat>εA:

`εΓ0 ≤ (εW+εΨ+εcontact+|Γeff_hat| εA)/(Ahat−εA)+εB`.

R4's design case (not achieved measurements) is |Γeff_hat|≤3500J/m², εA/Ahat≤0,002, εW/Ahat≤8J/m², εΨ/Ahat≤5J/m², εcontact/Ahat≤5J/m² and εB≤4J/m². This gives **29,05J/m²**, against target30J/m² for a hypothetical150J/m² intercept. This does not require independent Gaussian errors; shared systematic errors must lie in the same budget. If effective work exceeds the design's3500, or any port is missing, the bound is not achieved.

A nominal5mm×1,5mm incision has Ahat=7,5mm². Work budget8J/m² means60µJ. If only Ft has a constant bounded error, it corresponds to12mN; when both components share the same worst-case force budget over5mm and1,5mm movement, it becomes9,23mN. These are necessary budget examples, not an instrument recommendation or executed calibration. Area0,2% corresponds to0,015mm² in the example; pixel size alone does not certify that area. Terminal pre-cleavage at assumed6MPa traction requires about0,67µm opening budget for4J/m² if force error were zero; the traction is an older synthetic scenario, not a measured skin parameter.

Acceptance before fit: ≤20% central prediction error in work/force per prespecified held-out case, explicit joint uncertainty interval and independent injury-zone test. The same measured material, history and contact ports are given to a uniform fine cohesive/XFEM/phase-field control and the best conventional reusing operator. Physical acquisition, setup, cert, rebuild, fallback and query cost are counted before any cost advantage is claimed. No new FE is needed until these work ports exist.
