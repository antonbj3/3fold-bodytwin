# Final measurement specification: scalpel, working port and damage zone

PENDING_INDEPENDENT_REVIEW. This is a proposed acquisition, not performed trials, achieved precision, clinical protocol or verified power. Consumer: LANE_SURGICAL_RESPONSE. Target: BT-CTX-SURG-INCISION, GRAPH_INVERSE/MULTIPHYSICS.

Desired ability → cutting force, new gap and damage zone for a new tool from the same tissue history.
Conflicting requirements → work and actual new fracture surface must be measured simultaneously, while deformation, friction and pre-cleavage work must be identified independently.
Obstacles → a diameter/gauge series change phasing and contact simultaneously; peakforce and post-extraction crack length are not a common working port.
Modified operation → synchronous two-component force, 3D crack front and matched first-pass/repeat/precut-work, with explicit operation control and uncertainty ledger.

1. Fabric and lineage. Start with unfixed porcine full skin and separate anatomically documented layers; never transfer full skin toughness to a layer without measurement. Record animal, body location, age, thickness, temperature, hydration, freezing history, fiber orientation and biaxial bias. Six independent animals is a pilot default choice, not power calculation. Randomize adjacent samples, preserving that they are not the same sample. Keep an animal and an actual radius completely out of material/contact customization.
2. Tool. Measure the local edge radius along the entire active edge before and after each cut using calibrated profilometry/microscopy; store the curvature field and the uncertainty. Suggested manufacturing targets 1/5/20/50µm are planning values only; actual radius controls the analysis. Keep wedge/chamfer angle fixed in first radius series, then a separate angle intervention. Record surface finish, coating, previous use and tissue residues. Shaft diameter/2 must not be set as edge radius. Measure contact imprint and opening before blade arrival for possible connection to BINDINGS.
3. Synchronous work measurement. Calibrate Ft and Fn with cross-coupling and offset; record x(t),z(t), velocity, advance and bias load on the same clock. For example, run 1 och20mm/s and several penetration depths, but pre-record each stop. Integrate Wext=∫Ft dx+∫Fn dz, with the entire first-pass and ramp-up saved. Sampling rate and anti-aliasing are chosen according to measured instrument bandwidth so that the discretization error of the work is accommodated in the budget; 10Hz peak-only data is not enough. Fn has zero direct effect at dz=0; Fn/d is never a measured shear strength.
4. Crack area. Follow the actually advancing front with 3D imaging/DIC and subsequent slice imaging. Freeze the reference: a geometric crack plane area ΔA, not two free surfaces. Account separately for delamination, crushing, perforation, fracture orientation and any difference between loaded area and unloaded track. A delaminated microsurface must not be counted both in a macrocohesive work curve and in an added microsum. Residual marks and pinhole diameter are not automatic area observations.
5. Separate deformation and contact. Measure recoverable ΔΨ through documented unloading/reloading and included bias energy; use the layer operator from R2 only if its membrane/slip assumptions are empirically accepted. Measure Dcontact with precut/repeat through an actual comparable path, contact area, speed and bias. Second and third passages quantify conditioning/operation; if the spreading/frictional work changes between passages, the difference must not be entirely attributed to Γ. Keep that difference as a nuisance port and run both similarity closure and measured drift control.
6. Γ and micromechanics. Effective Γ_cut=(Wext−ΔΨ−Dcontact)/ΔA. For chemical Γ0, in addition, independent B_before is required: Γ0=Γ_cut−B_before. BINDINGS full-terminal traction/opening-work, newly added interface area and fiber break/pullout must come from matched lineage. A partial hysteresis loop or a radius close to zero does not identify B_before. Γ_pierce and Γ_cut remain different assay ports until the same skin, crack kinematics and process mechanisms are measured. Measure the needle insertion first/same-hole/3th pass with the same working port as the scalpel.
7. Damage zone to RESPONSE. Define width as the distance normal from the measured fracture front, per side, layer and time. Report mechanical strain zone, irreversible matrix damage, membrane permeability/cell viability and perfusion loss separately. Perform spatial viability/membrane assay directly and at exempelvis24h, plus vessel imaging with caliber, tightness and pre/post flow. A mechanical strain threshold must first be compared to this independent observation; it is not a measure of necrosis. No pin track width is taken as avascular edge to RESPONSE. Wound gap and bleeding flow are measured separately, with suture/margin conditions documented.

## Frozen prospective error budget

Exact bounded quotient error bound, when Ahat>εA:

`εΓ0 ≤ (εW+εΨ+εcontact+|Γeff_hat| εA)/(Ahat−εA)+εB`.

R4's design cases (not achieved measurements) are |Γeff_hat|≤3500J/m², εA/Ahat≤0,002, εW/Ahat≤8J/m², εΨ/Ahat≤5J/m², εcontact/Ahat≤5J/m² and εB≤4J/m². That gives **29,05J/m²**, against target30J/m² for a hypothetical150J/m² intercept. This does not require independent Gaussian errors; shared systematic errors must be in the same budget. If effective work exceeds the design's3500, or any port is missing, the bound is not achieved.

Acceptance before fit: ≤20% central prediction error in work/force per prespecified stop, explicit joint uncertainty interval and independent damage zone test. The same measured material, history and contact ports are given to uniform fine cohesive/XFEM-/phase field control and best conventional reuse operator. Physical acquisition, setup, certificate, rebuild, fallback and inquiry costs are counted before any cost advantage is claimed. No new FE is required until these working ports exist.
