## What the intersection actually showed

**The premise of the brainstorm was largely wrong.** It assumed that it adds external anchors that the project lacks. The project already holds 114 bound external measurement anchors with verbatim excerpts and sha256. The value is in the handful of anchors that hit a **named internal obstacle**, not the volume. From 324 questions, 102 themes became: 34 COMPUTED, 29 PARTIAL, 36 NEW, 3 PLANNED. Of these, 23 is HIGH. Of the surgical wave 78 themes are 11 `EXISTS_IN_GRAPH_ENGINE` and 6 `ALREADY_EXCLUDED`.

**The biggest work saved: "hundred experts to a dense search algorithm" is the engine we already have.** All twelve proposed operators point to existing functions. Building it had been the single biggest waste of the entire material.

**Seed's bearing assumption is already answered, in its favor, but only in direction.** The dense model beats oracle-routed specialists by 0,059 / 0,094 / 0,248 bpb at n = 2 / 8 / 32, with total corpus and number of steps constant over n *per construction* and the decision rule pre-registered. But the run has `seed: 0` and no replication, so 0,059 at n = 2 is indistinguishable from run noise. The direction at n = 32 is citable; the margin is not.

**The robot's binding limit is registration time, not sensory.** At 150 s per registration, collection is 0,002 % of the chain. Against the target budget 1,08 mm: brain shift +195 %, pivot deviation 110 %, tremor 1,0 %, optical error 0,1 %. Three out of four headline gaps are far from binding.

**The path to a revised regulatory framework is a measurement, not a specification.** All 15 mechanics nodes are regulatory inert. Note 1 in rule 22 includes external subsystems, so wire versus voice is what can make the rule incoherent: if the wire wins, the rule classifies the measurably worse configuration as lower risk. We already have the human route’s numbers.
